# 英文三路能力与 NevIR 受控问题复现实测

日期：2026-09-07。用途：确认现有系统能否处理英文，并在实际三路候选中检验近似段落的成对错排。负责人已授权独立子任务测试英文能力，能力得到支持后推进 NevIR；没有实现新排序算法、训练模型或恢复全量 T2。研究定义见[研究计划 §1.1](../plans/post-recall-research-plan.md#11-当前阶段先验证问题存在且可复现)。

## 1. 独立英文能力实测

独立子任务事先一次性编写 8 篇普通英文多主题正文和 6 条查询（3 条字面、3 条释义），在独立 eval 存储中完成真实入库及项目召回。全部样本保留，模型、阈值和深度没有为结果作调整。它是基础能力检查，不是抽样的研究评测集，也不检验否定区分。

| 当前通道 | 目标进入该路结果 | 目标严格第一名 |
| --- | ---: | ---: |
| Dense：`text-embedding-v4`，1024 维 | 6/6 | 6/6 |
| Learned Sparse：`doubao-embedding-vision-251215` | 5/6 | 5/6 |
| SQLite FTS5 BM25：当前项目实现 | 6/6 | 5/6 |

六题均完成真实候选采集且无调用失败。三条字面查询和两条释义查询的三路目标均严格第一名。面包释义查询在 Sparse 的 0.20 阈值下返回空，BM25 将目标排第二；不通过降低阈值或替换查询追求通过。

因此机器判定保留 `partial`：预设的 18 项全部严格第一名条件没有达到。三路已有直接的英文主题辨别证据，足以开展有明确限制的 NevIR 小规模诊断；不能改写为英文全面适用。最新 Sparse 单次预检成功，历史欠费在本轮没有复现。

追加的旧 LambdaMART 检查只消费这六题已保存的完整候选。冻结 final33 模型严格目标第一名 6/6，现有在线策略也为 6/6，全部 `ltr`、无回退、无模型首位同分；特征和分数离线重放一致。它减少了“连普通英文主题都无法排序”的疑虑，仍不能排除 NevIR 领域偏移或证明否定能力。

证据：[独立说明](../../runs/post_recall/english-capability-20260907/README.md)、[固定 fixture](../../runs/post_recall/english-capability-20260907/fixture.json)、[逐路结果](../../runs/post_recall/english-capability-20260907/summary.json)、[旧基线英文检查](../../runs/post_recall/english-capability-20260907/baseline-english.json)。该任务实际编码请求为 Dense 7 次、Sparse 15 次（含预检 1 次），全部成功；后续排序检查没有远端请求。独立 SQLite、FTS、Qdrant 均为 8 条，没有编码截短。

## 2. NevIR 输入与执行口径

采用[作者发布的 NevIR](https://huggingface.co/datasets/orionweller/NevIR) 原始 Validation：225 个配对中的全部正文，按解码后的 Unicode 字符串完全相等去重，得到 340 段。未按抽中查询、正例或排序表现筛选语料，近似但不同的版本全部保留。从原始行序以独立 `random.Random(20260907).sample(rows, 20)` 抽 20 组，两条查询分别执行，共 40 条；不补抽、不补入漏召回的段落。本轮未读取 Test 实例。

每段使用独立匿名文档和单个 chunk，不把官方配对或改写家族伪装成同文档关系。官方配对只保存在评价映射中，不进入入库或排序代码。其他背景段落保持未判断，未生成训练负标签。采集输入、完整逐路结果及排序正文保留原文，不要求外部资料补全。

| 运行内容 | 实际取值 |
| --- | --- |
| 独立 dataset / Qdrant collection | `995200` / `eval_nevir_validation_20260907_9` |
| 本地 corpus / BM25 | 本次运行目录的 `storage/corpus.sqlite3` / `storage/bm25.sqlite3` |
| 三路深度 | Dense 150、Sparse 50、BM25 100 |
| 分数阈值 | Dense 0.30、Sparse 0.20；BM25 沿用当前 FTS 查询 |
| 融合权重 | Dense 0.70、Sparse 0.15、BM25 0.15 |
| 候选 | 各路实际全部返回项的去重并集；逐路 rank 从 0 开始 |
| 正文与编码 | 三处存储均核对 340 段；两路均发送完整正文，无截短、无未知长度 |
| 实际编码请求 | 文档 Dense 41、Sparse 340；查询 Dense 40、Sparse 40；全部 HTTP 200，无额外重试 |
| 被测排序器 | `models/candidate-difference-v3-20260728-final33`，原 38 维、33 棵树；不重训 |

**BM25 保留当前实际实现。** 配置 coarse/fine 为 2/1，但现有 SQL 将两项权重传给前两列未索引字段，实际文本列为默认 1/1。本轮在元数据同时记录配置与实际行为，没有先修复再称其为原系统。当前英文预分词还会去重词项；不能把结果称为标准词频 BM25 的英文基准。

预备输入在召回前已写入：[准备记录](../../runs/post_recall/nevir-controlled-20260907/prepared/preparation.json)、[全部语料](../../runs/post_recall/nevir-controlled-20260907/prepared/corpus.jsonl)、[固定查询](../../runs/post_recall/nevir-controlled-20260907/prepared/queries.jsonl)、[独立配对映射](../../runs/post_recall/nevir-controlled-20260907/prepared/pairs.jsonl)。执行证据为 [run.json](../../runs/post_recall/nevir-controlled-20260907/run.json)、[入库核对](../../runs/post_recall/nevir-controlled-20260907/ingest-completion.json)、[全部候选](../../runs/post_recall/nevir-controlled-20260907/candidates/inputs.jsonl)、[请求与完成统计](../../runs/post_recall/nevir-controlled-20260907/completion.json)。

## 3. 真实共同召回

40 条查询全部 `ready`，没有调用失败或查询被省略。指定的两个段落在**三路合并候选中共同出现 40/40**；20 组的两条查询都共同覆盖。每题完整候选数为 35–116，平均 99.975。

| 通道 | 返回数量范围 | 成功返回空的查询 | 指定两段均在该路的查询 |
| --- | ---: | ---: | ---: |
| Dense | 3–24 | 0/40 | 35/40 |
| Sparse | 0–11 | 12/40 | 24/40 |
| BM25 | 35–100 | 0/40 | 40/40 |
| 三路并集 | 35–116 | 0/40 | 40/40 |

这里的“在三路之后”指三路实际结果的并集，不要求两段同时出现在每一路。Sparse 的空结果是成功响应后阈值下无命中，不能写成 API 故障，也不能隐藏这一通道较弱的事实。小背景与现有较深 BM25 返回范围有利于共同覆盖，因此 40/40 不能外推到大库。逐路描述见[召回观察](../../runs/post_recall/nevir-controlled-20260907/retrieval-observation.json)。

## 4. 排序与复现

在每题实际完整候选池上运行冻结 LambdaMART，评价侧按官方配对关联偏好。没有向排序器传配对标签、来源家族或配套查询。

| 结果 | 数量 |
| --- | ---: |
| 模型分数严格符合官方单查询偏好 | 22/40（55%） |
| 模型分数严格逆序 | 18/40 |
| 指定两段模型同分 / 无法算分 | 0 / 0 |
| 同组两个查询都严格正确 | 4/20（20%） |
| 在线实际模式 | 40 次均为 `ltr`，无回退 |
| 在线最终顺序 | 22 条符合偏好、18 条逆序，与原始模型分数判定一致 |

这是共享候选中、已共同召回条件下的成对结果；不是作者原始双文档实验的成绩。每组只有一个方向正确也不计入“双查询都正确”。18 条逆序首先表示与官方偏好不一致，尚不能全部称为经过独立人工确认的反例。

首次评价对每题重新构建特征并重算分数，40/40 一致。随后在独立输出目录中从保存的原始候选输入重放，全部候选的分数、确定性模型次序与成对结果完全相同；在线模式与最终次序本次也相同。该核对没有再次编码或检索，不要求远端 ANN 每次都返回完全相同的候选。根任务另核对了抽样种子、340 段原文集合、全部 SQLite 正文、查询原文和两个评价输出，统计一致。

证据：[首次评价](../../runs/post_recall/nevir-controlled-20260907/evaluations/summary.json)、[独立目录重放](../../runs/post_recall/nevir-controlled-20260907/replay/summary.json)、[根任务核对](../../runs/post_recall/nevir-controlled-20260907/root-verification.json)。离线评价脚本的 4 项小型合成检查覆盖缺失查询／失败分母、同分、单方向错误、回退和模型分数分开、完整背景以及重放差异；它们只验证评价逻辑，不冒充真实研究结果。

### 一个可解释的错排：不识字的是谁

固定抽样的第二组 `471-2`，第一条查询 `q0002` 问：谁自己不识字，却能够逐字背诵大段经文？两段主体都叫 Harry Hosier，但所述条件不同：

| 候选 | 正文支持的条件 | 模型分数 | 完整 103 候选中的名次 |
| --- | --- | ---: | ---: |
| A：官方偏好段落 | Hosier 本人不识字，但能背诵经文 | −0.203476 | 2 |
| B：另一近似段落 | Hosier 本人会阅读、能背诵；不识字的是部分听众 | −0.188284 | 1 |

这条查询实际执行了三路召回：Dense 与 BM25 都返回 A/B，Sparse 成功返回空。排序时 A/B 已经在场，正文包含区别，最终却把 B 放在 A 前；不是漏召回，也不是补入标准段落或模型同分破局。两段都涉及“不识字”，但它对应的人不同，因而与最初关于关键细节及其对应关系的担忧直接相关。

独立文本子任务在不读取排序结果的情况下复核了抽样清单的前五组，包含此组；其对 q1 的偏好可由正文直接解释。q2 的时间顺序措辞较强，这一疑点保留，但不改变 q1 中“本人不识字／本人会读”的区别。另一个 `557-3` 配对存在查询未限定哪次参议院行动的歧义，仍留在全部 20 组原始统计中，不作为这里的清楚反例。[文本复核](../../runs/post_recall/nevir-controlled-20260907/review-first5.json)是范围有限的 AI 阅读，不是人工金标，并披露其中三组在之前讨论中已读过。

本例用于说明已观察的现象，是看结果后从上述前五组中选出的解释案例，不是重选评测样本或筛出“适合方法”的成绩子集。A/B 的 38 维输入中有 **13 列不同**，所以本例不能证明“特征完全相同导致失败”。需要保留的结论是现有模型在这份固定完整输入上发生了可重放错排；是否源自特征表示、训练分布或三路证据的使用方式，尚未确定。[完整案例](../../runs/post_recall/nevir-controlled-20260907/witness-471-2-q1.json)保留查询、两段全文、逐路分数／排名、模型分数及不同特征名。

## 5. 证据边界与资产

这是一轮开发用途的受控观察。它不估计自然搜索中的发生频率，不证明新方法有效，不证明错误由 38 维表示单独造成，也不证明所有年份、对象、单位或条件差异都适用。普通英文六例的基线通过不消除领域偏移、中文专门特征及训练分布的影响。

官方标签只支持指定段落对的偏好，不能据此计算完整池 nDCG、整体 Top-1 质量或用户答案错误率。独立 AI 阅读用于解释具体例子与保留疑点，不是新增人工金标；不得据其适合与否筛掉原 20 组的结果。

本轮未动 T2 已完成的 14,700 段及历史资产；账户当前可用不触发全量 T2 自动恢复。没有新算法实现、commit 或 push。
