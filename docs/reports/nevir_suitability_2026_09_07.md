# NevIR 适用性核查：数据观察与证据边界

## Material Passport

- 日期：2026-09-07；性质：公开数据结构审计、固定样本阅读与代码审计，不是模型效果实验。
- 问题：NevIR 是否值得用于检查“三路固定候选中，差异定位能否超过充分单候选局部匹配”。
- 来源：[作者论文](https://aclanthology.org/2024.eacl-long.139/)、[作者数据](https://huggingface.co/datasets/orionweller/NevIR)、[作者评测代码](https://github.com/orionw/NevIR)、当前工作树，以及负责人转交的 GPT6 PRO 审查。审查意见作为讨论材料，不作为实现指令。
- 工作方式：academic-research-suite 的实验规划检查项；根任务阅读样本，独立子任务核查来源、划分与代码。没有独立人工复标，没有调用编码服务、创建索引、训练模型或修改运行代码。

## 1. 判断

> 后续阶段对齐：本报告中的方法信号观察保留原身份。当前先用现有材料检验问题存在且可复现，尚不要求证明候选比较增量；现行范围见[研究计划 §1.1](../plans/post-recall-research-plan.md#11-当前阶段先验证问题存在且可复现)。这项对齐不改变本报告已观察的数据事实，也不表示已经启动实验。

后续已授权并完成的独立英文测试、340 段共享语料召回及基线错排重放见[实测报告](nevir_controlled_retrieval_2026_09_07.md)。本报告以下“未实测”的表述仍描述此前离线核查阶段，不作为当前进度。

**NevIR 适合提供受控的关键差异证据，值得进入一次小规模英文通道与共同召回检查；尚不支持确定新方法有效，或直接替换正式主评测集。**

它提供了几乎相同的段落以及方向相反的查询偏好，能够减少“先从海量语料寻找目标对”的成本。原文中的否定、动作对象与作用范围均可在正文内观察，符合“只利用已有排序输入”的信息边界。但原版每次只排两个段落；共享语料中的实际三路候选是另外一层实验，需要重新定义覆盖与条件性成绩。

本轮还观察到：极窄的“查询必须命中差异词”触发方式缺乏支持；部分查询存在事件范围不明确的问题；少量完全重复正文跨官方划分出现。这些都是需要处理的具体限制，不足以否定整个数据集，也不应通过挑选方法能解的样本来消除。

研究假设与后续设计只在[研究计划](../plans/post-recall-research-plan.md#34-nevir-的候选用途与最小衔接检查)维护。本报告保存证据，不冻结窗口、阈值、表示或新排序结构。

## 2. 来源、结构与划分核查

论文 §3 说明：段落来自 CondaQA 的自然正文及人工否定编辑，排除仅改写措辞而不改变意义的版本；配套查询由人工编写。查询要求回答为文本片段，排除是非问答，并限制直接使用只在一侧段落出现的词。作者承认这项词面限制并不完美。论文的人类正确率检查仅涉及三名标注者各判断十个随机实例，不能据此宣称所有公开标签已经独立复核。[论文](https://aclanthology.org/2024.eacl-long.139.pdf)

本轮下载作者原始三个 JSONL 文件，保留原顺序与正文。下载时间、上游版本及 URL 集中记录在 [provenance.json](../../data/post_recall/nevir/provenance.json)，不另建文件哈希台账。

| 官方划分 | 配对行数 | 查询条目数 | 段落条目数（未去重） |
| --- | ---: | ---: | ---: |
| Train | 948 | 1,896 | 1,896 |
| Validation | 225 | 450 | 450 |
| Test | 1,383 | 2,766 | 2,766 |
| 合计 | 2,556 | 5,112 | 5,112 |

每行含 `id / WorkerId / q1 / q2 / doc1 / doc2`。公开标签由字段语义给出：q1 对应 doc1，q2 对应 doc2；它不是覆盖全部共享语料的 qrels。作者数据卡说明 ID 前段为 CondaQA 来源编号、后段为编辑编号。本轮确认同一前缀内部的 doc1 相同；WorkerId 是查询编写者编号，不是文档家族，不进入排序输入。[数据卡](https://huggingface.co/datasets/orionweller/NevIR)

**机器核查发现了有限但真实的跨划分重复。**

- 完整配对 ID 和 ID 前缀均没有跨划分重叠，Train 与 Validation 也没有完全相同正文。
- Train 与 Test 共享 1 个完全相同正文，涉及 Train 的 2 行、1 个来源前缀；Validation 与 Test 共享 3 个完全相同正文，涉及 Validation 的 6 行、3 个来源前缀。Test 侧合计涉及 7 行。
- 合并 doc1/doc2 检查仍是上述 4 个重叠正文；仅压缩空白不会新增跨划分重叠。
- Validation 合并两段并按完整字符串去重后是 **340 个正文**；Train＋Validation 为 **1,761 个正文**，全体三个划分为 **3,838 个正文**。近似但不同的编辑版本保留，不能做语义合并。
- Train、Test 各有 1 行 q1 与 q2 完全相同，却要求在同样两个段落上给出相反次序。在相同输入下，确定性排序不能同时满足两项严格偏好。这是机器可以确定的监督冲突，不是模型未理解否定的证据；没有删除、改写或替换这些行。

详细计数、家族关联与局限见 [audit.json](../../runs/post_recall/nevir-suitability-20260907/audit.json)。Test 只由程序用于结构和重复检查，没有抽取、展示或人工阅读其正文、查询或标签实例。六个已阅读样本按来源前缀／完全相同正文关联到 Test 的数量为 0；此检查不排除文章级或其他语义同源关系。

这证明“按来源 ID 前缀隔离”尚不足以保证正文不重复；不证明已经造成某模型的分数虚高。共享检索库里存在待评文档本身也不等于监督泄漏。真正要避免的是把同一基础正文或其已知改写的训练／调参反馈当作独立测试证据。相同原文与来源前缀可以组成简单的关联组；这仍不能保证不同段落不来自同一篇文章，当前公开字段与审计没有证明文章级完全隔离。

## 3. 六组固定样本：全部保留，不按可解性替换

抽样规则在读取结果前确定：使用一个 `random.Random(20260907)`，先从原始 Train 顺序抽 3 行，再从 Validation 顺序抽 3 行，均不放回。抽中 Train 的零起始行号 227、932、193；Validation 的 105、53、204。完整查询和两段原文保存在 [samples.json](../../runs/post_recall/nevir-suitability-20260907/samples.json)。以下用中文概述含义，原始数据没有翻译或改写。

**六组的公开标签均为 q1：A 在 B 前；q2：B 在 A 前。** 下表的合理性分析是本轮阅读判断，不是新的人工金标。

| 来源／ID | 配套查询的含义 | A／B 的关键区别 | 对本研究的意义与疑点 |
| --- | --- | --- | --- |
| Train `200-3` | q1 找获准返回那不勒斯的女性及丈夫；q2 找不被允许返回者 | A：雇佣兵没有阻止 Joanna I 夫妇返回；B：阻止他们返回 | 差别在否定所作用的动作。只数否定词可能把“没有阻止”误当成“不允许”。未阻止与正式许可的措辞也并非完全等同，需保留解释边界。 |
| Train `93-2` | q1 找未获得巴塞尔大学职位的人；q2 找获得职位的人 | A：Euler 申请该校职位失败；B：赴俄邀请被撤回，转而以巴塞尔已有教授职位邀请作为退路 | 同样出现失败含义，却对应不同职位和行动。读到否定并不等于知道它否定了哪件事。B 的邀请与实际任职是否完全等价，也应按统一标签口径复核。 |
| Train `186-3` | q1 找技术普及后不再被视为 AI 的现象；q2 找普及后仍被视为 AI 的现象 | A：普及后不再算 AI；B：普及后算 AI；两段均把现象称作 AI effect | 关键区别非常局部，正文已提供判断依据。这适合受控区分；判断依照给定文本，不是要求系统查证改写后的世界事实。 |
| Validation `504-3` | q1 找不用手的舞；q2 用双重否定询问相反情况 | A：通常不用手；B：通常用手；对象都是 circular hey | 改动很小，但 q2 的表达拗口，且原文限定“通常”。不能因文本短就声称这是简单、零歧义的真值。 |
| Validation `473-3` | q1 找避免公开表态政体偏好的作家类别；q2 找没有避免表态者 | A：Machiavelli 所属作家避免表态；B：公开表态；关于启蒙思想家的另一句话也被改动 | 需把动作归到正确人群；差异位置不止一处。找到任意改动不保证找到查询所需改动。 |
| Validation `557-3` | q1 找没有采取行动的治理机构；q2 找采取行动的机构 | A 末尾：参议院没有继续行动；B 末尾：通过加入动议。但两段前面都写参议院曾批准加入 | **查询没有限定哪一次行动。** 按末尾事件可理解公开标签，但 q2 也可能由 A 的前文回答。这是需独立复核的实际疑点，不能按其不利于方法而删掉。 |

这些样本符合“判断所需差异位于输入正文”这一条件。它们不证明实际三路已共同召回 A/B，不证明当前 LambdaMART 已错排，也不能估计自然搜索中此类问题的频率。六组均进入开发观察范围，不能再充当独立效果确认。

## 4. 观察到的信号与不能跳过的对照

本轮做了一个很窄的离线文本检查：小写 ASCII 词项、保留内部撇号，不做词干化或停用词过滤；计算查询是否含只在其中一段出现的词。**12 条查询里，11 条没有这种直接命中。** 唯一命中来自 `200-3` 的 q2 中的否定词，但它命中的 A 实际表达“没有阻止”，并非“不允许”。这与作者试图限制词面捷径的设计相符。[lexical-observation.json](../../runs/post_recall/nevir-suitability-20260907/lexical-observation.json)

这项结果只否定一种过窄的直觉：有差异词命中就足以判断偏好。它不是所有窗口方法的性能实验：编辑区中的词可能也出现在两段的公共部分，附近语境仍可能提供信息，字符匹配也与上述词项统计不同。不能由 11/12 推出所有差异表示必然无效。

当前代码的实际边界如下：

- [38 维特征](../../src/linkrag_eval/retrieval/learning_to_rank/experiment.py)的否定词表只有中文；英文的专门否定两列为零。分句处理包含部分英文标点，但不包含英文句号及英文连接词。字符二／三元组、数字、标识符、三路分数与池统计仍有信号，不能称 38 维完全看不到英文区别。
- 若每个 NevIR 段落使用独立 doc_id，两列同文档比较特征为零；全池字符频率和三路相对分数仍在。不能为了激活两列而把官方配对或改写家族伪装成排序可见的同文档关系。
- [BM25](../../src/linkrag_eval/store/sqlite_bm25.py)已有英文词项，小写化、不过滤否定词，但不理解否定作用范围。当前还会去重词项，不能把它等同于保留原词频的标准英文 BM25。
- [旧训练包装](../../src/linkrag_eval/retrieval/learning_to_rank/experiment.py)把不在正例列表内的候选全部标成 0，不能原样用于 NevIR 的未判断背景。应先在完整池上计算特征，再仅让有标签依据的关系参与损失；不能缩小特征计算池或给背景虚构负标签。
- Dense 支持英文的产品说明、客户端能接收英文，都不等于已经验证该端点的否定／关系辨别能力。Sparse 的实际英文输出、检索和当前账户状态，本轮均未重新测试。

另有一个与科研方法无关的工程缺口：FTS 表前五列不建索引，文本在后两列，但 `bm25()` 只收到两个列权重；依据 [SQLite 的逐表列权重规则](https://www.sqlite.org/fts5.html#the_bm25_function)，当前文本列使用默认权重 1，声明的 coarse/fine 权重没有作用到相应文本列。实测前应修正或如实固定当前口径，对所有方法一致，本轮没有改代码。

充分的单候选对照应共享英文适配、单候选局部计算、原有池统计、监督划分与调参预算。差异方法只多获得“由其他候选帮助选择检查位置”这一项。AI 例子中，单候选扫描本来就可能找到否定短语；只有差异方法在同样能力下多解决了问题，才支持候选比较的增量。当前没有测得这项增量，也没有理由先追加一个新语义模型。

## 5. 官方双文档与共享候选的评价边界

官方 paired accuracy 要求 q1 下 A 分数严格高于 B，同时 q2 下 B 严格高于 A；任一方向同分均不记正确。逐查询准确率与双查询都正确的比例不同。[作者 scorer](https://github.com/orionw/NevIR/blob/main/src/negations/dense.py#L67)

对共享语料，需要首先记录全部预定查询的三路列表及其并集。q1、q2 分开执行；排序器不同时读配套查询，也不读取官方配对 ID、修改位置或 WorkerId。A/B 只有实际出现在当前池中才可比较，不能补入漏召回的一侧。

| 可报告的量 | 分母与含义 |
| --- | --- |
| 单查询共同召回覆盖 | 全部预定查询中，A/B 同时进入该查询三路并集的数量／比例；各路覆盖可另外列出 |
| 可评单查询的相对次序 | 仅上述有 A/B 的查询，统计方向正确、错误、同分；各方法共用召回固定的分母 |
| 双查询共同覆盖 | 全部预定配对中，q1、q2 的各自候选池都包含 A/B 的数量／比例 |
| 条件双查询正确率 | 仅双查询共同覆盖的配对，检查两个方向是否都正确；同时报告计数、同分和缺失 |

若按模型分数判断，延续严格大于规则；若另看实际输出顺序，固定与标签无关的破平局规则，单列同分后顺序，不能把顺序优势冒充严格分数区分。没有可评实例时比例为不可估计，不写成零。查询失败、空池和缺失不补抽，配套查询及已知家族不当作相互独立样本。

即使 A 排在 B 前面，两者也可能都在很后面。公开成对标签不给其他候选负例资格，因此上述结果不能推出 Top-1、全列表 nDCG、全库召回率或总体答案质量提升，也不能冒充官方原版完整双文档成绩。保留原版可作为单独诊断，但它不替代三路候选衔接。

## 6. 尚未解决

1. 六组阅读中的事件限定、许可与结果措辞等疑点，尚无独立人工复核；不能据此报告标签正确率。
2. Sparse 英文通道及账户服务是否可用，尚无新的真实验证。
3. 实际三路共同召回多少标准对、冻结模型及充分单候选基线错多少，尚未测量。
4. 英文共享特征、仅消费已判断关系的训练接入、分组及同分评价，尚未实现为 NevIR 实验流程。
5. 候选差异如何带来单候选表示以外的信息，仍只是待检验假设；本轮观察没有给出可冻结的新方法。

T2 的既有 14,700 段、向量、索引与代码保留。本轮不恢复 T2 编码，也不据其前缀标签观察判定 T2 整体不合格。是否继续 T2 作为自然数据路线，属于后续资源与证据选择，不是进入 NevIR 小规模检查的前置条件。
