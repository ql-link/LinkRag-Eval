# 英文候选标注 v2：可用模型辅助

完成自己包里的全部 122 条即可。一人可以在模型辅助下完成本任务，不要求必须有第二位真人；若安排第二人复核，两包案例相同，但顺序和 X/Y 不同，分别交回结果，不按题号抄录。

## 打开与填写

1. 完整解压 ZIP，双击 review.html，用桌面 Chrome、Edge、Firefox 或 Safari 打开。无需安装软件、登录或联网，不要在 ZIP 预览里填写。
2. 先阅读 GUIDE.md，填写姓名或稳定代号，选择标注方式。使用模型时，写一行工具／模型名称和用途；只做翻译辅助也选“模型辅助”。版本不清楚就写实际知道的名称，不必猜测。
3. 每题可展开“用模型辅助”，复制提示词给你使用的模型，请它中文解释、指出关键英文依据并建议类别。核对后填入你确认的偏好、一个主要类别、1–3 句中文或英文理由。已有参考偏好可以质疑。
4. 点击“完成并下一题”；不能可靠判断的，写明原因后点击“保留待讨论”。仅翻页或输入草稿不会自动标成已完成。
5. 最后勾选本人逐条确认的声明，点击“导出最终结果”，把下载的 JSON 原文件交回负责人。若仍有未处理项，先“下载草稿备份”，如实说明进度。模型生成且未由你确认的内容保留为草稿。

## 保存与恢复

页面会尝试自动保存到当前浏览器，顶部会显示是否成功。但本地存储可能因浏览器、清理缓存或移动文件而变化，因此每次离开前都应点击“下载草稿备份”，保留最新 JSON。

再次打开后可用“导入已有 JSON”恢复自己的草稿或最终结果。只接受相同 v2 标注包；导入会替换当前草稿，因此先下载备份。不要导入另一位标注者的文件，也不要手改包编号、案例编号或 X/Y。若已填写旧 v1 包，原样交回负责人，保留已有工作，不修改旧填写声明冒充新的过程。

若浏览器提示本地存储不可用，仍可填写、导出和导入；不要仅依赖自动保存。若页面无法打开，联系负责人并说明浏览器及错误，不用截图代替完整结果文件。

blank-answers.json 是尚未填写的空白模板，仅作格式参考；不要把它当成完成稿提交。部分未完成、保留争议和以前见过的材料均应如实保留。

每位实际标注者交回一份最终 JSON。使用模型不使判断失效，研究中按“模型辅助、人工确认”描述其来源；一人与模型协作不计为双人独立标注。若与其他人共同讨论后形成结果，在辅助说明中一并写明。页面离线运行；把题目复制给模型是你在相应工具中的操作。
