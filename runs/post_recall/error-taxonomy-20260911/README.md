## 回收

收到一份最终 JSON 即可运行：

    .venv/bin/python runs/post_recall/error-taxonomy-20260911/prepare.py receive \
      --reviewer-1 /绝对路径/标注者1-final.json \
      --out runs/post_recall/error-taxonomy-20260911/received-日期

若两份都已收到，在同一命令中加 `--reviewer-2 /绝对路径/标注者2-final.json`；也支持仅收包 2。输出目录必须不存在。脚本检查包身份、完整性、类别、理由、实际辅助方式及本人确认声明，保存原提交，输出 reviewer-labels.jsonl、uncertain.jsonl、disagreements.jsonl 和 receipt.json。辅助信息随每条对齐结果保留，不自动生成共识。确认框属于提交者声明，不是独立验证证据。

一份提交时不计算双人一致率，未决项仍单列。两份提交时，描述性相符率分母为双方都明确分类的案例；按实际 chunk ID 对齐偏好，不直接比较 X/Y，不将其自动解释为无辅助的独立人工可靠性。若两份来自同一人，请只收一份。收到真实提交后形成 labels.jsonl 与 docs/reports/error_taxonomy_<日期>.md：单人逐条确认可形成最终分类，未决项保留；有第二人则保留原始复核与分歧处置。报告说明实际人数与辅助过程。
