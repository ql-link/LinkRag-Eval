1. 你的任务是什么

你不是来判断“哪个评审员更可靠”，也不是来帮助实验得到某个结果。你要做的是： 针对每个分歧案例，依据 Query、Reference 和 Candidate 三段文字，给出一个独立、唯一、可解释的最终人工判断。

任务 A：关系仲裁

判断参照是否有效、目标事实是否唯一、候选与参照是等价还是事实冲突，以及冲突属于哪一类。

工作量：7 行。

任务 B：相似度仲裁

只判断两段文本在语义内容上的接近程度，用 1–7 的整数评分；事实正确与否不能自动决定相似度。

工作量：96 行。

一句话抓住核心： “事实关系”和“语义相似度”是两个不同问题。两句话可以非常相似，却只在一个数字上互相冲突； 也可以都谈同一主题，却没有在说同一件事。
本指南中的例子不是实际研究数据。 例子中的机构、设备、日期、人物和规则均为教学用途的虚构内容，不能复制到正式提交文件中。

2. 必须遵守的信息边界

独立性比“猜中研究团队想要什么”更重要。请在整个任务中遵守下面的边界。

你可以查看

  • 本指南；
  • human_tasks/r2-adjudication/relation/README.txt；
  • human_tasks/r2-adjudication/relation/cases.csv；
  • human_tasks/r2-adjudication/relation/submission_template.csv；
  • human_tasks/r2-adjudication/similarity/README.txt；
  • human_tasks/r2-adjudication/similarity/cases.csv；
  • human_tasks/r2-adjudication/similarity/submission_template.csv；
  • 普通词典，用于确认单词字面含义，但不要上传整行文本。

你不得查看或使用

  • facilitator 目录、自动模型分数或分带；
  • 候选的生成来源、构造角色或预期答案；
  • 实验通过条件、先前实验结果或其他仲裁员的最终提交；
  • 搜索引擎、外部事实核查、LLM、翻译模型或自动评分工具；
  • 任何“为了让实验通过应该怎样打分”的建议。
如果有人告诉你“应该多打某个分数”“某类候选应该统一判成某标签”或“这样实验才会通过”，请暂停任务并联系协调人。 仲裁必须由文本本身决定，不能由期望结果决定。

不要联网核实虚构事实。 在本任务中，Reference 是待检查的参照文本；你需要判断它是否在当前案例中回答了 Query， 并比较 Candidate 与它的关系，而不是调查这些名称在现实世界是否存在。

4. 每一行都采用“两遍阅读法”

两位原评审的答案会出现在 reviewer_a_value 和 reviewer_b_value 中。它们是待仲裁的意见，不是答案键。

1第一遍：独立判断

  1. 先把 A/B 两列隐藏、折叠，或用纸遮住；
  2. 只读 Query、Reference、Candidate；
  3. 写下你自己的暂定标签或分数；
  4. 用一句话指出决定判断的文本片段。

2第二遍：审阅分歧

  1. 再查看 A/B 原始值及 uncertain 状态；
  2. 检查是否遗漏了版本、否定、条件或单位；
  3. 保留或修正自己的判断；
  4. 不要机械取平均，也不必强行选择 A 或 B。

对关系任务，A/B 值通常是一个 JSON 对象；对相似度任务，通常形如 {"score":6}。 你可以选择 A、选择 B，或给出另一个合法值，但必须由文本依据支持。

5. 关系仲裁：逐字段说明

关系任务不是问“这两段话像不像”，而是问“它们对同一个事实说了什么”。

5.1 先把 Query 拆成五个部分

  1. 实体：问题在问谁或什么？
  2. 事实槽：问的是数量、时间、状态、权限、条件，还是其他属性？
  3. 时间或版本：是否限定“当前”“第几版”“截至某日”？
  4. 方向：允许还是禁止、增加还是减少、存在还是不存在？
  5. 适用条件：是否限定地区、人群、型号、阶段或触发条件？

5.2 提交列与合法值

列名合法值初心者解释
adjudication_id 模板已给定 原样保留，不能改、不能重新编号。
valid_reference yes / no Reference 是否直接、完整地回答当前 Query，并满足其时间、版本和条件。
unique_target_group yes / no Query 与 Reference 是否指向一个边界清楚、不会产生两套互不兼容答案的目标事实。
target_relation equivalent / factual_conflict Candidate 与 Reference 对同一目标事实给出相容答案，还是给出互不相容的答案。
conflict_type 空白或四类之一 只有 factual_conflict 才填写；equivalent 时必须保持真正的空单元格。
uncertain yes / no 完成全部比较后，是否仍存在会改变标签的实质性歧义。
notes 简短文字 uncertain=yes 时必须填写；其他情况下强烈建议写明决定性依据。

5.3 判断流程

Reference 是否回答 Query？ 如果否，填 valid_reference=no。
目标事实是否唯一？ 如果存在无法合并的两种合理解释，填 unique_target_group=no。
Candidate 是否在说同一实体、事实槽、时间和条件？ 逐项对齐，不要只看关键词。
答案相同或相容？ 填 equivalent，并让 conflict_type 保持空白。
答案互不相容？ 填 factual_conflict，再选且只选一个主冲突类型。
仍有会改变结论的歧义？ 填 uncertain=yes，并在 notes 中明确缺少什么。
如果 Reference 无效或目标组不唯一： 仍不要把模板中的其他必填列留空。请填写当前文本下最可辩护的关系值，同时设置 uncertain=yes，在 notes 中明确说明资格缺陷。不要为了“完成任务”把 no 改成 yes。

5.4 四种事实冲突

numeric｜数值

同一量、同一单位口径、同一适用范围下，数字、区间、比例、序号或量级不相容。

不要误判：90 分钟与 1.5 小时换算后相等，不是冲突。

version_time｜版本或时间

把错误版本、年份、生效期、截至日期或历史状态当成 Query 所问的版本或时间。

不要误判：Query 明确问旧版时，旧版信息不是因为“过时”就错误。

negation_direction｜否定或方向

允许/禁止、增加/减少、支持/反对、存在/不存在等结论方向相反。

不要误判：不能只数“否定词”；要看整句含义是否真的反转。

applicability_condition｜适用条件

改变决定结论成立的人群、地区、型号、阶段、阈值或触发条件。

不要误判：无关修饰语缺失，不构成条件冲突。

冲突类型只能选一个。 如果同一候选似乎同时改变两个决定性事实槽，先判断哪一个变化直接造成答案不相容；若不能稳定选出主类， 仍填写最可辩护的一类，并设 uncertain=yes 说明多重变化。

5.5 关系任务最常见的错误

  • 看到文本非常像，就直接判 equivalent；
  • 看到 Candidate 与 Reference 不同，就直接判数值冲突，而没有先核对单位和口径；
  • 把阈值条件中的数字变化误判为 numeric，忽略它其实改变了适用范围；
  • target_relation=equivalent 时填写 none 或 not_applicable；正确做法是让 conflict_type 单元格真正空白；
  • 因为 A/B 有分歧，就自动填写 uncertain=yes。分歧本身不是不确定性的理由。

6. 相似度仲裁：1–7 分怎么打

相似度任务只回答：“Candidate 与 Reference 在语义内容和表达结构上有多接近？” 不回答：“Candidate 是否正确？”

事实冲突不等于低相似度。 “设备可运行 18 小时”和“设备可运行 16 小时”几乎整句相同，只在一个数字上冲突；它们仍可能是高度相似文本。

6.1 七点行为锚定量表

7
命题等价
事实、关系、时间和条件相同，只是措辞、语序或句法变化；两段可以互相替换而不改变答案。
6
极高相似
近似复述，或只有一个非常局部的事实槽不同；主体、事件框架和绝大多数内容保持一致。
5
高度相似
明显在说同一事实框架，但存在较显眼的结构改写，或一个关键事实槽/关系发生变化。
4
同一事件框架
核心事件或任务相同，但多个关键槽、参与者角色或语义关系不同，不能视作近似复述。
3
同领域或同实体
共享领域、实体或背景，但讲的是不同事件、谓词或事实槽。
2
宽泛主题重合
只有大主题或少量词语重合，无法对齐到同一事件或同一事实。
1
基本无关
主题、实体和事件都不同，几乎没有可解释的语义对应。

6.2 临界分数的四个判断问题

纠结位置问自己倾向
7 还是 6？ 两段是否表达完全相同的命题，互换后答案不变？ 是 → 7；有任何决定性事实差异 → 不应为 7。
6 还是 5？ 差异是否只是一个局部槽，且其余结构几乎逐项对应？ 几乎逐项对应 → 6；重写或差异更显眼 → 5。
5 还是 4？ 是否仍能清楚对齐同一事实框架，且主要只变一个关键点？ 主要一个关键点 → 5；多个槽或关系改变 → 4。
3 还是 2？ 是否共享明确实体或事件类型，而不仅是同一大主题？ 有明确实体/事件联系 → 3；只有大主题 → 2。

6.3 相似度评分的固定步骤

  1. 忽略“哪句正确”，先找共同实体与事件；
  2. 标出可一一对应的谓词、角色、时间、数量和条件；
  3. 判断差异是零个、一个局部槽，还是多个关键关系；
  4. 先选大区间：1–2、3–4、5–7；
  5. 再用上面的临界问题确定唯一整数；
  6. 最后才查看 A/B 分数，检查自己是否遗漏文本细节。
不要为了“使用完整量表”而强行制造分布。 每一行只按它自身的文本证据评分。同样，也不要因为前几行都打了 6，就刻意把下一行压成 5。

7. 虚构标注案例

下列案例由本指南作者专门为培训设计，全部为虚构内容。为方便学习，部分案例同时展示关系与相似度答案； 正式任务中必须仍按两个物理目录分开完成。建议先自己判断，再展开“参考解析”。

案例 1：单位换算后的等价表达

equivalent · 7 分
Query 云岬温室的备用照明可以连续运行多久？
Reference 云岬温室的备用照明可连续运行 90 分钟。
Candidate 该温室的备用灯续航为 1.5 小时。

模拟分歧：A 认为是数字冲突、相似度 6；B 认为等价、相似度 7。

展开参考解析

90 分钟等于 1.5 小时。实体、事实槽、单位换算后的值和适用范围都一致，所以不是数字冲突。

关系：yes / yes / equivalent / [空白] / no
相似度：7

示例 notes：“90 分钟与 1.5 小时换算后相等，表达同一续航命题。”

案例 2：只改变一个数量

numeric · 6 分
Query 澄海号一次标准巡航携带多少枚采样盒？
Reference 澄海号标准巡航配置 12 枚采样盒。
Candidate 澄海号标准巡航配置 14 枚采样盒。

模拟分歧：A 判 numeric、相似度 6；B 判 version_time、相似度 5。

展开参考解析

没有任何版本或时间变化；唯一变化是同一单位下的 12 与 14。两句几乎逐词对应，因此事实冲突与高相似可以同时成立。

关系：yes / yes / factual_conflict / numeric / no
相似度：6

示例 notes：“同一标准巡航和同一单位，仅采样盒数量 12/14 不相容。”

案例 3：当前版本被旧版本替代

version_time · 5 分
Query 截至 2032 年 6 月，银栈港当前执行哪一版靠泊规程？
Reference 第四版靠泊规程自 2032 年 3 月起生效，目前执行第四版。
Candidate 银栈港现阶段仍按第三版靠泊手册办理船舶进港。

模拟分歧：A 判 version_time；B 因两句措辞不同而只关注相似度，关系填成 equivalent。

展开参考解析

Query 明确询问当前执行版本。Reference 说第四版，Candidate 说仍执行第三版，结论互斥；冲突核心是版本状态。表达有明显改写，但事实框架相同。

关系：yes / yes / factual_conflict / version_time / no
相似度：5

案例 4：允许与禁止的方向反转

negation_direction · 6 分
Query 雨桥实验室是否允许研究员在夜间单独进入？
Reference 夜间不得单人进入雨桥实验室。
Candidate 研究员夜间可以独自进入雨桥实验室。

模拟分歧：A 判 negation_direction、相似度 6；B 判 applicability_condition、相似度 5。

展开参考解析

适用范围都是研究员、夜间、单独进入；变化的是“不得”与“可以”的许可方向，所以主类是否定/方向，而不是适用条件。

关系：yes / yes / factual_conflict / negation_direction / no
相似度：6

案例 5：阈值数字其实决定适用条件

applicability_condition · 5 分
Query 星纱电池在什么情况下需要启动前预热？
Reference 只有环境温度低于 −10°C 时，星纱电池才需要预热。
Candidate 无论环境温度是多少，星纱电池每次启动前都必须预热。

模拟分歧：A 因看到 −10°C 判 numeric；B 判 applicability_condition。

展开参考解析

−10°C 不是待回答的“输出数量”，而是规则何时生效的阈值。Candidate 把“仅低于阈值”扩大为“所有温度”，改变的是适用条件。

关系：yes / yes / factual_conflict / applicability_condition / no
相似度：5

案例 6：英文重度改写但命题相同

equivalent · 7 分
Query Who may authorize night access to the Lantern Archive?
Reference Only the duty curator may authorize night access to the Lantern Archive.
Candidate After dark, permission to enter the Lantern Archive can be issued solely by the curator assigned to that shift.

模拟分歧：A 给 6 分，认为句法变化明显；B 给 7 分，认为命题可互换。

展开参考解析

the duty curator 与 the curator assigned to that shift 在本句中表达同一角色；night 与 after dark 相容。没有事实变化，结构改写不妨碍命题等价。

关系：yes / yes / equivalent / [空白] / no
相似度：7

案例 7：同一实体，但讲的是不同事件

相似度练习 · 3 分
Reference The Aurora rover completes a full battery charge in four hours.
Candidate The Aurora rover cleans its optical sensors every four hours.

模拟分歧：A 给 2 分；B 给 4 分。

展开参考解析

共享明确实体 Aurora rover，也共享“四小时”这一表面片段，但谓词和事实槽完全不同：一个讲充电时长，一个讲清洁频率。它们不是同一事件框架，因此更接近 3，而不是 4。

相似度：3
提醒：此例只训练相似度，不代表正式关系任务会出现第三类关系标签。

案例 8：只有宽泛主题重合

相似度练习 · 2 分
Reference 青屿观测站每周三校准主天线的方位传感器。
Candidate 多座海岛科研站正在推广可回收包装材料。

模拟分歧：A 给 1 分；B 因“海岛科研站”这一主题联系给 3 分。

展开参考解析

两句都与海岛科研设施有关，但实体、事件、谓词和事实槽都无法对齐。仍有一点宽泛主题联系，所以 2 比 1 或 3 更合适。

相似度：2
1 分对照：若 Candidate 改为“厨房里的面包在傍晚出炉”，才属于基本无关。

案例 9：出现两个可能的主冲突

uncertain 练习
Query 2031 版规范要求哪类巡检员每隔多久复查冷却阀？
Reference 2031 版要求高级巡检员每 20 天复查一次。
Candidate 2029 版规定所有巡检员每 45 天复查一次。

模拟分歧：A 判 version_time；B 判 applicability_condition；两人都指出还存在周期数值变化。

展开参考解析

版本、人员范围和周期都变化，已经不是理想的“单一事实槽变化”。如果无法稳定确定哪一个是决定性主冲突，应如实保留不确定，而不是假装只有一个变化。

一种可辩护填写：yes / yes / factual_conflict / version_time / yes
notes：“候选同时改变版本、适用人员和复查周期；暂以 Query 明示的 2031 版为主类，存在多重冲突。”

这里的重点不是规定必须选 version_time，而是示范：当主类不能由文本唯一确定时，必须把歧义写出来。

不要把示例答案当成打分模板。 正式案例可能比示例更短、更长或更模糊。你的任务是复用判断原则，而不是复用示例中的数字或标签比例。

8. 什么时候使用 uncertain，notes 怎么写

8.1 uncertain=yes 的适用情形

  • 关键指代缺失，不知道“它”“该版本”指什么；
  • 单位或统计口径缺失，无法判断两个数是否可比；
  • Query 可以合理解释成两个互不兼容的目标事实；
  • Candidate 同时改变多个决定性事实槽，无法稳定选择唯一主冲突；
  • 英文或中文句法存在两种都会改变最终标签的合理解析。

8.2 不应使用 uncertain=yes 的情形

  • 只是因为 A 与 B 不一致；
  • 案例需要多读一遍，但文本最终可以判断；
  • 你担心自己的答案与大多数人不同；
  • 你不知道研究团队希望得到什么结果；
  • 你不想在 5 和 6 之间作出选择。应重新使用临界分数问题，选出更合适的唯一整数。
uncertain 不是第三种关系标签，也不是跳过按钮。 即使填 uncertain=yes，其他字段仍须填写当前证据下最可辩护的值，notes 必须说明具体歧义。

8.3 好 notes 与坏 notes

质量示例为什么
好 “90 分钟=1.5 小时；实体、时长和适用范围一致。” 指出可复查的决定性依据。
好 “Candidate 同时改变版本和适用人群，无法唯一确定主冲突类型。” 明确说明不确定来自哪里。
坏 “我觉得 A 对。” 没有文本依据。
坏 “模型可能更喜欢这个答案。” 模型偏好不属于人工真值证据。
坏 “太难了。” 没有说明哪一处歧义会改变标签。
