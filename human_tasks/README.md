# 人工作业入口

本目录只放“交给人操作”的浅入口，不保存第二份研究真值。

当前任务：

- R2 独立仲裁：进入 [`r2-adjudication/START_HERE.html`](r2-adjudication/START_HERE.html)。

使用规则：

1. 只进入协调人指定的任务目录；
2. 先打开该目录唯一的 `START_HERE.html`；
3. 不追踪符号链接去寻找其他版本、其他研究员或 facilitator 文件；
4. 按指南在当前浅入口中生成 `submission.csv`；
5. 完成后通知协调人，不再修改提交。

机器权威制品仍保存在版本化研究目录中。浅入口只是安全、简短的人机界面，提交锁、manifest 和最终分析仍在机器权威层执行。
