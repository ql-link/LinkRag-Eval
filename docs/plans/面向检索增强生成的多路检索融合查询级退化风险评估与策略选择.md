## 一、正式选题

### 1.1 中文题目

**面向检索增强生成的多路检索融合查询级退化风险评估与策略选择**

### 1.2 英文题目

**Query-Level Degradation Risk Assessment and Strategy Selection for Multi-Retriever Fusion in Retrieval-Augmented Generation**

### 1.3 候选标题对比与定稿理由

| 候选标题 | 优点 | 主要问题 | 结论 |
| --- | --- | --- | --- |
| 面向检索增强生成的多路检索融合策略风险—收益评测 | 与既有工程和实验包贴合，表述稳妥 | 范围偏宽，容易被理解为常规横向比较；“风险—收益 + 排名融合”与经典 IR 研究的措辞和问题设定过近 | 不采用，保留为历史题目 |
| **面向检索增强生成的多路检索融合查询级退化风险评估与策略选择** | 明确研究现象是“查询级退化”，明确论文输出是“策略选择”，能把负向结果、跨域差异和部署门禁组织成一个完整问题 | 标题较长；“策略选择”必须有预先定义的判定规则，不能只给经验建议 | **正式采用并冻结** |
| 面向检索增强生成的多路检索融合查询级退化分析与评测框架 | 不暗示发明新算法，学术风险较低 | 仍容易落回“做了一个评测框架”，对《计算机科学》的方法贡献表达偏弱 | 作为保守备选，不作为当前题目 |
| 面向检索增强生成的风险校准选择性残差融合方法 | 方法感和创新上限更高 | 需要真正的新算法、校准目标、理论或强实验结果；当前项目尚无相应证据，且容易与自适应检索和形式化风险控制工作撞车 | 不采用，仅可作为未来独立方法研究 |

最终选择新题目的原因不是包装出“算法创新”，而是把已有系统最有价值、也最可验证的学术问题说清楚：融合策略的平均提升可能掩盖部分查询退化，论文需要以成对的查询级证据识别这种退化，并据此作出可审计的离线选型。相较原题目，新题目缩小了研究对象、强化了决策输出，也避开了与既有“rank fusion risk–reward”题名的直接近似。

采用新题目的代价是审稿人会追问“风险如何定义、如何进入选择规则”。因此，只有完成第 2.4 节的查询级指标、第 2.5 节的统计检验以及第 2.6 节的预冻结选型协议，题目中的“风险评估与策略选择”才成立。

### 1.4 研究对象与术语边界

研究限定在 RAG 的检索与排序阶段，比较稠密检索、稀疏检索、BM25、固定权重融合、
RRF 和学习排序等策略。不以生成答案质量为主要研究对象，也不把检索指标提升直接解释为
生成质量提升。

生产 RAG 项目 `LinkRag` 提供被测检索能力，独立项目 `LinkRag-Eval` 负责数据集管理、
检索执行、算分、统计检验、报告和实验产物留存。

本文的“查询级退化”特指：在相同查询、语料、qrels 和评测预算下，候选策略相对冻结基线 S4 的单查询检索指标下降。它不是查询扰动鲁棒性、对抗攻击风险、生成幻觉风险或具有概率覆盖保证的形式化安全风险。

本文的“策略选择”特指：根据公开测试前冻结的规则，在全局或领域层面决定哪一种融合策略进入 Shadow 或部署候选。它不指按每条线上查询动态选择检索器，也不训练新的在线路由器。标题中的“查询级”修饰退化风险评估，而不是宣称“逐查询在线选策略”。

### 1.5 核心研究问题

- **RQ1：平均收益。** 不同融合策略相对固定权重生产基线，能否稳定改善 Recall、MRR、
  nDCG 和 Hit 等检索指标？
- **RQ2：查询级风险。** 平均指标提升是否掩盖部分查询的排名退化，不同策略的退化率、
  退化幅度和最坏尾部表现有何差异？
- **RQ3：跨领域稳定性。** 策略结论能否在不同中文公开领域以及项目真实场景之间迁移，
  哪些收益仅存在于特定查询类型或数据域？
- **RQ4：离线策略选择。** 综合平均收益、查询级风险、统计不确定性和运行成本后，如何形成
  可预先冻结、可复现、可审计的全局或领域级融合策略选择规则？

### 1.6 核心论点

论文拟检验而非预设以下论点：

> 仅报告平均检索指标不足以支持融合策略选择；可部署决策还应同时考察查询级退化、
> 跨领域稳定性、统计不确定性和运行成本。

论文允许得到正向、负向或混合结果。不得为了获得正向结论而反复使用测试集调参。

### 1.7 预期贡献边界

最低可辩护贡献为：

1. 构建一套面向 RAG 多路检索融合、以可信生产基线为参照的查询级退化风险评估与离线选型协议；
2. 将平均收益、退化比例、条件退化幅度和最坏尾部表现组织成成对、带不确定性的证据，而不是仅报告平均分；
3. 通过中文公开多领域数据与项目真实场景检验策略结论的跨域稳定性和失效边界；
4. 将离线效果、运行成本和 Shadow/回滚门禁连接为可复现、可审计的策略选择依据。

上述贡献属于**评估与决策方法创新 + 系统性实证创新**，不属于新检索模型创新。单个退化指标、风险—收益思想和排名融合均有明确前人工作，论文不得声称首创；可辩护的新意来自针对 RAG 多路异构检索场景的严谨组合、预冻结选择逻辑、中文跨领域证据与真实系统验证。

本文不主张：

- 发明新的神经检索模型或通用学习排序算法；
- 给出具有数学覆盖保证的“安全检索”或“风险控制”方法；
- 使用曝光日志、点击倾向校正或反事实学习排序；
- 证明检索指标提升必然带来生成答案质量提升；
- 把 `LinkRag-Eval` 的工程实现本身作为唯一创新。

在没有形式化风险保证前，论文统一使用“退化风险评估”“风险—收益分析”等表述，不使用
“安全保证”“风险受控学习”等过强名称。

### 2.2 待比较策略

所有策略使用相同语料、查询、候选深度、Top-K、编码器版本和查询预处理口径。

| 编号 | 策略 | 角色 |
| --- | --- | --- |
| S1 | BM25 | 词法检索基线 |
| S2 | Dense | 稠密语义检索基线 |
| S3 | Learned Sparse | 学习型稀疏检索基线 |
| S4 | Fixed Weighted Fusion | 当前可信生产基线 |
| S5 | Reciprocal Rank Fusion（RRF） | 无监督秩融合基线 |
| S6 | LambdaMART v3 | 学习排序策略 |
| S7 | LambdaMART v3 + 回退/保护 | 可部署学习排序策略 |

S6 与 S7 必须同时保留，用于区分学习排序本身的效果与回退、Top-K 保护等工程机制的效果。

### 2.3 训练、调参与测试纪律

- S1—S5 不使用测试 qrels 调参；所有权重、阈值和 RRF 参数必须在测试前冻结；
- S6—S7 在每个公开数据集上采用固定查询级 5 折 OOF 评测，测试折不得参与训练、早停、
  阈值选择或特征筛选；
- 超参数如需搜索，应在训练折内部完成，形成嵌套训练/验证结构；
- 另执行三组 leave-one-domain-out 实验：两个公开领域训练，一个未见领域测试；
- 数据划分以固定随机种子和查询 ID 哈希生成，保存 split manifest；
- 同一测试结果不得因结论不理想而重新划分或废弃；
- Blind v5 不进入任何公开数据模型的训练、融合权重选择或停止决策。

### 2.4 指标体系

#### A. 平均效果指标

- `Hit@5`、`Hit@10`；
- `Recall@5`、`Recall@10`；
- `MRR@10`；
- `nDCG@10`。

当前 `_metrics` 只返回是否命中和首个相关结果的倒数排名，并不是真正的多正例 Recall。
正式实验前必须补充基于完整 qrels 的 Recall 和 nDCG 实现，且在单元测试中覆盖零正例、单正例、
多正例和并列相关等级情况。

#### B. 查询级风险指标

以 S4 Fixed Weighted Fusion 为主要参照，对每个查询计算策略指标差值
`delta(q) = metric_strategy(q) - metric_baseline(q)`，至少报告：

- Win/Tie/Loss 查询数及比例；
- Hit-loss rate：基线 Top-K 命中而候选策略未命中的比例；
- Rank-harm rate：候选策略 `RR@10` 低于基线的比例；
- Mean harm magnitude：仅在退化查询上计算的平均负向差值绝对值；
- Worst-decile delta：查询差值最差 10% 的平均值；
- 按领域、查询长度、词法/语义特征和结构化查询类型分层的风险指标。

除上述直观统计外，最优选择层投稿版本至少纳入一种经典风险敏感检索度量（如经原论文公式核对的
`U_Risk` 或 `T_Risk`）作为相关方法对照，说明本文的描述性风险统计和选型协议相对既有 IR
风险—收益分析增加了什么，而不是重新命名已有度量。

不得只报告“gained/lost Hit”。即使没有 Hit 损失，也必须检查 MRR 和 nDCG 的排名退化。

#### C. 运行成本指标

- 端到端延迟 `p50/p95/p99`；
- 排序或融合阶段的独立耗时；
- 候选数量和各路召回数量；
- fallback、timeout、error、budget-exceeded 比例；
- 若不同策略产生额外模型调用，报告每查询调用次数和估算成本。

延迟实验在预热后至少重复 3 轮。涉及远端 Qdrant 或编码器的结果应标记为观测性证据，
不得把无法控制的网络波动解释为融合算法的因果效果。

#### D. 主指标与风险统计对象

- 冻结 `nDCG@10` 为主要连续效果指标，`Hit@10` 为主要离散失效指标；`MRR@10`、
  `Recall@5/10` 和 `Hit@5` 为次要指标；
- 对策略 `s`、查询 `q` 和指标 `m`，统一定义成对差值
  `d(s,q,m) = m(s,q) - m(S4,q)`；
- 平均收益、退化比例、仅在负差值上的条件平均退化幅度和最差 10% 查询的平均差值，
  必须从同一份逐查询差值表计算；
- 主要结论以 `nDCG@10` 的平均差值和下尾风险、`Hit@10` 的 gained/lost 配对变化共同决定，
  不允许在看到结果后更换“主指标”；
- 论文不把上述任一统计量命名为新指标，也不宣称它们具有分布无关或有限样本风险保证。

### 2.5 统计检验

- 对 MRR、nDCG、Recall 的基线差值报告查询级配对 bootstrap 95% 置信区间；
- 对连续或有序指标的主要比较执行双侧配对随机化检验；
- 对 Hit 变化执行 exact McNemar 检验；
- 每个数据集内，所有策略相对 S4 的主要比较使用 Holm 方法校正多重检验；
- 同时报告绝对变化、相对变化、置信区间和校正后 p 值，不能仅凭 `p < 0.05` 下结论；
- bootstrap、随机化检验和模型训练均保存随机种子与重复次数。

### 2.6 预冻结的离线策略选择协议

正式测试前，在 experiment manifest 中冻结非劣界值 `delta`、允许的 Hit-loss 上限
`tau_hit`、最坏尾部下限 `tau_tail`、p95 延迟预算以及并列时的优先级。具体数值应由业务容忍度、
Tune 集和测量误差共同确定，不得读取测试结果后再设定。

候选策略按以下门禁串行判定：

1. **证据有效门禁：** 数据版本、qrels、OOF/未见域划分、运行产物和统计检验全部有效；
2. **平均效果门禁：** 主要指标成对差值置信区间下界不低于 `-delta`，即通过预设非劣检验；
3. **查询级退化门禁：** Hit-loss 置信区间上界不超过 `tau_hit`，最差 10% 查询的平均差值
   不低于 `-tau_tail`；
4. **成本门禁：** p95 延迟、超时、错误和额外调用成本不超过冻结预算；
5. **择优规则：** 仅在通过全部门禁的策略中，按“主要指标平均收益 → 下尾风险 → 运行成本”的
   冻结优先级选择；若无候选通过，则保留 S4，不强行选出新策略。

领域级选型只有在领域标签、最小查询量和判定阈值于测试前冻结时才允许。本文最低版本不实施
逐查询在线路由，不用测试查询训练策略选择器，也不把离线分层分析包装为动态融合算法。

“差异不显著”不等于“非劣”。若样本量不足以支持非劣结论，应标记证据不充分，而不是默认候选安全。

### 2.7 最低消融实验

必须完成以下消融：

1. Dense、Learned Sparse、BM25 单路与融合策略对照；
2. 固定权重融合与 RRF 对照；
3. LambdaMART 原始排序与加入固定权重 blend 的对照；
4. 有无短查询回退的对照；
5. 有无 baseline Top-K 保护的对照；
6. 域内 OOF 与跨领域直接迁移的对照。

如果回退和 Top-K 保护同时变化，应增加单独消融，避免无法识别收益来自哪个组件。

### 2.8 查询分层与错误分析

最低分层包括：

- 短查询与普通长度查询；
- 词法精确查询与语义描述查询；
- 编号、日期、版本号等结构化查询；
- 单正例与多正例查询；
- 各公开数据领域；
- 策略显著改善、显著退化和各策略均失败的典型案例。

案例分析不得只挑选支持预期结论的查询。每类案例应按冻结规则抽样，并对私有内容脱敏。

### 2.9 可复现性要求

每次正式运行必须记录：

- Git commit SHA 和 dirty worktree 状态；
- 数据集名称、revision、文件摘要和许可证检查结果；
- dense、sparse、BM25 的模型与配置 fingerprint；
- 语料 chunk、query、qrels 和 split manifest 的摘要；
- 所有融合参数、阈值、随机种子和依赖版本；
- 单查询结果、聚合指标、统计检验和错误案例索引；
- 运行环境、候选预算、超时与回退配置。

公开复现包至少包含数据适配代码、配置模板、固定 split manifest、指标实现和聚合结果；
不得包含 `.env.eval`、API key、私有语料或可还原的业务查询。

### 2.10 最低完成标准

论文进入写作阶段前，必须同时满足：

1. 三个中文公开数据集均完成 S1—S7 的同口径比较；
2. 学习排序结果全部来自无测试泄漏的 OOF 或未见领域评测；
3. 完整报告平均效果、查询级风险、运行成本和统计不确定性；
4. 完成最低消融、跨领域迁移和预先规定的错误分析；
5. 公开实验能够由固定 revision、配置和随机种子复现；
6. 对非显著结果、负向结果和适用边界如实报告；
7. 不复用 Blind v5 调参，任何新私有主实验使用新的预冻结 Tune/Blind 数据；
8. 结论限定在检索与排序阶段，不外推生成答案质量；
9. 第 2.6 节的门禁阈值、择优顺序与基线保留规则在正式测试前冻结，并保存完整决策记录。

最低完成标准不要求所有融合策略优于基线。只要实验设计有效、数据和统计充分，跨领域差异、
局部退化或简单基线优于复杂策略都可以成为论文结果。

## 四、研究叙事纪律

- 若平均指标提升且风险下降，可结论为“在给定数据与门禁下更适合部署”；
- 若平均指标提升但局部风险上升，应结论为“存在收益—风险权衡”，不能宣称全面优越；
- 若复杂策略不优于固定权重或 RRF，应将其作为有效负向结果并分析适用边界；
- 若私有数据与公开数据结论不一致，应优先报告域差异，不选择性删除数据集；
- “生产可用”必须由工程门禁与 Shadow 证据支持，“效果显著”必须由预设统计检验支持；
- 论文中的所有数字必须能够追溯到不可变运行产物。

### 5.3 创新性判断

**总判断：中等偏应用、条件成立，不是零创新，也不是方法首创。** 题目可以继续，但创新性必须按层次诚实表述：

| 层次 | 判断 | 说明 |
| --- | --- | --- |
| 多路检索、RRF、LambdaMART 与回退机制本身 | 低 | 均有成熟前作或既有工程实现，不能作为主要创新 |
| “平均提升会掩盖查询退化”这一问题意识 | 低至中 | 经典 IR 排名融合研究已经直接讨论，RAG 生产研究也已观察负增益 |
| RAG 多路检索的查询级退化评估协议 | 中 | 若统一基线、成对统计、下尾风险、非劣门禁和成本门禁全部预先冻结，可构成清晰的方法性组合贡献 |
| 中文公开多领域 + 独立真实系统证据 | 中 | 价值取决于 qrels 质量、领域差异是否真实出现、是否完整报告负向结果 |
| 从逐查询证据到 Shadow/部署候选的可审计选型链 | 中 | 工程基础较强，但必须把判定规则形式化并与普通“看平均分选最好”实证区分 |

最强的反对意见将是：“论文只是把若干标准 IR 指标、统计检验和工程门禁拼成一套检查表，没有新算法、
新理论、新数据集或新指标。”要抵御这一意见，最低实验包之外的关键不是强行修改已经可上线的系统，
而是做到以下四点：

1. 用数学定义和预注册 manifest 固化评估对象、主指标、非劣与风险门禁，形成真正可执行的决策协议；
2. 正面复现并比较经典 rank-fusion risk 指标，不把旧概念包装成新指标；
3. 用三个公开领域和一个独立真实场景证明平均收益、查询退化与成本排序可能给出不同决策；
4. 发布逐查询结果结构、split manifest、统计代码和选择记录，使结论可复核，而不只展示系统截图或汇总表。

如果最终数据没有显示任何有意义的策略差异，论文仍可报告负向结果，但对两个最优期刊的贡献强度会下降；
此时需要依靠充分功效分析、跨域一致性和对“复杂融合为何无额外价值”的机制证据，而不能只写“差异不显著”。

### 5.4 允许与禁止的创新声明

允许使用：

- “构建一套面向 RAG 多路检索融合的查询级退化风险评估与离线选型协议”；
- “系统比较平均收益、查询级损害、下尾表现、跨域稳定性与运行成本”；
- “在冻结的中文多领域数据和真实系统证据上揭示适用边界”；
- “为融合策略进入 Shadow/部署候选提供可复现的经验性决策依据”。

禁止使用：

- “首次发现融合会导致查询级退化”或“首次提出检索风险—收益评估”；
- “提出新的风险指标”，除非后续确有新定义、理论性质和充分对照；
- “实现查询级动态最优策略选择”，因为当前协议是离线全局/领域选型；
- “保证安全”“控制错误率”“具有覆盖保证”或“证明生成质量提升”；
- “达到通用最优”或把单一私有场景结果外推到所有 RAG 系统。

### 5.6 最终选题决议

**维持并冻结题目“面向检索增强生成的多路检索融合查询级退化风险评估与策略选择”。**

该题目当前属于“有明确历史前作、存在部分撞车、但通过边界收紧后仍可形成独立论文”的方向。继续推进的
前提是：策略选择保持离线含义，风险保持经验评估含义，经典风险融合工作被正面引用和比较，三个公开领域

“多路检索融合策略的跨领域实证评测”，不再使用当前题目中的“风险评估与策略选择”。
