# 英文候选错误类型标注指南 v2

2026-09-11 按负责人后续安排允许模型辅助、人工确认；七类定义、案例和参考偏好沿用 v1。可由一人完成，第二位复核者可选。

每条包括查询、X/Y 两段正文和已有参考偏好。请判断：哪段更符合查询，以及区分这两段最关键的语义因素是什么。参考来自已有官方标记或人工裁定，可以质疑；它不是必须照填的答案。

1. 只依据包内正文，不上网补事实。可以使用模型翻译、解释、建议偏好和类别，再由你逐条确认。中文解释用于辅助理解，判断依据仍是所给英文文本；看不准时保留待讨论。
2. 填你自己的偏好：X / Y / 两段相当 / 无法判断。没有提供证据，不等于明确否定；答案词或人名相同，也不代表同样满足条件。
3. 选一个主要类别，写 1–3 句理由，指出关键短语或条件（可以直接摘录英文）。不需要翻译全文，也不需要给候选打分。

| 主要类别 | 判断依据 |
| --- | --- |
| 否定范围 | 关键是 not、never、without 等否定作用于哪个动作、条件或范围；不能只因出现 not 就选此类。 |
| 主体归属 | 关键是某动作、属性或否定属于谁，包括指代和跨句归属。 |
| 比较方向 | 关键是更多／更少、高于／低于、先后、数量或界限的方向。 |
| 改述或反义 | 关键是不同词语或表达之间的同义／反义对应，例如 accept 与 refuse，而非直接匹配字面。 |
| 额外限制 | 核心主题或动作相同，但还需满足附加的时间、对象、条件或多个条件的组合。 |
| 标签争议 | 你认为现有参考偏好缺乏正文支持、应当相当／反向，或题目本身不能可靠比较；必须说明争议。 |
| 其他 | 上述类别均不能准确概括；请具体说明因素，不用“其他”代替没读懂。 |

多个因素同时存在时，优先选择直接决定两段差异的一项，其他因素写入理由。例如不同人物分别承担同一否定动作，优先“主体归属”；变化主要是数量界限，优先“比较方向”。若你的偏好与参考不同且确认为参考有问题，选“标签争议”，并在理由中说明具体语义因素。

确实无法裁定时，填写原因并点“保留待讨论”；类别可以留空。不要为了完成数量猜标签。已知输入或技术失败由负责人另行处理，你只判断可见文本。模型身份、分数、前轮分析和他人的标签均不在包内。

本任务是对已选错误案例的描述性分类，不能从一次标注推断模型内部出错机制，也不估计全数据集的错误比例。新意见不覆盖原始标签或既有成绩。记录实际使用的模型／工具和用途；模型本身不计作第二位真人。若有第二位复核者，分别保留提交及分歧，提交间相符程度不能自动解释为独立人工可靠性。
